A simple booking workflow

Follow these steps when handling a new room reservation.

  1. 01

    Choose a room

    Open Rooms and select the room the guest wants to reserve.

  2. 02

    Enter reservation details

    Provide the check-in date, check-out date and requested guest details.

  3. 03

    Submit the booking

    Submit the form and check that the application confirms the reservation.

  4. 04

    Verify and generate the bill

    Check the saved booking in the system before preparing its bill.

Helpful reminders

A few checks help keep hotel records accurate.

  • ✓ Use the correct numeric Guest ID when booking a facility for an existing guest.
  • ✓ Verify both check-in and check-out dates before submitting a room reservation.
  • ✓ Check the booking record before generating a bill.
  • ✓ Keep guest details accurate so that billing records can be matched correctly.
Note: A success message should always be followed by a check of the saved booking record. The dashboard does not display live booking counts unless those values are supplied by the Flask route.
